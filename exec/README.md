# GitJob 포팅 산출물

이 디렉터리는 `develop` 브랜치의 소스와 2026-09-28 운영 환경을 기준으로 작성한 포팅 자료다.

## 제출 항목

1. [빌드 및 배포 가이드](./01_build_and_deploy.md)
2. [외부 서비스 가입 및 설정 가이드](./02_external_services.md)
3. [최신 DB 덤프 및 복구 안내](./03_database/README.md)
4. [시연 시나리오](./4_시연_시나리오.md)

## 보안 원칙

- `.env.service`, `.env.data`, `.env.ci`, PEM, 토큰, 비밀번호는 Git에 올리지 않는다.
- 문서에는 환경 변수 이름과 발급·배치 방법만 기록한다.
- 운영 서버의 실제 값은 각 서버 또는 Jenkins Credentials에서만 관리한다.
- DB 덤프에는 운영 데이터가 포함될 수 있으므로 제출 채널 외에는 배포하지 않는다.
